### ⑤ 验证方法本身出过错 → **L-015**
首次验收用 `--no-checkout` 克隆后直接 `git ls-files -s` / `git config -f .gitmodules`，
得到**空输出 + pathspec 报错**，一度像「gitlink 未登记（半套接入）」。
真因：`--no-checkout` **不建索引**（`ls-files` 读索引故恒空；`.gitmodules` 未落盘；`submodule` 无法按 pathspec 定位）。
→ 「空结果被当成结论」的**第三次**（L-009 管道 / L-014 stderr / L-015 前置状态），但**根因各不相同**，不能只堵一个入口。

### ⑥ 存储值 vs 生效值
`.gitmodules` 与 `.git/modules/*/config` 的**存储值**是干净的 `https://github.com/...`；
`git remote get-url` 显示的是被全局 `insteadOf` 改写的 `https://ghfast.top/...`。
对**公开**仓只读取用，镜像重写不涉及凭证，无害 —— 但报告/排障须区分这两个值。
