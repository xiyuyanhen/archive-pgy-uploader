# archive-pgy-uploader 版本更新索引

本目录记录项目的每次正式迭代。文件名格式：`v{主版本}.{次版本}.{修订号}.md`。

## 版本规范

| 变更类型 | 版本号递增 | 示例 |
| --- | --- | --- |
| 破坏性变更、架构重构、首个可用版本 | 主/次版本 +1 | 0.x → 1.0.0 |
| 新能力、逻辑优化 | 次版本 +1 | 0.1.0 → 0.2.0 |
| 文档修正、排障补充、校准 | 修订号 +1 | 0.1.0 → 0.1.1 |

每次迭代须同步更新：
- `STATUS.md` 的 frontmatter 与受影响章节（实现真相索引 + 交接主文档）
- `changelog/CHANGES.md` 的条目级流水（`CR-NNN`）
- 本目录下对应版本文档
- 若涉及执行经验，追加 `experience/LESSONS.md` 与 `experience/execution-log.json`

> **变更入口**：所有变更先读 `STATUS.md` §8 变更管理协议，再按流程执行。

## 无版本变更的条目

**不改变宿主调用行为**的变更（文档修正、错别字、排障补充、不改变行为的校准）只记入 `CHANGES.md` 的 `CR-NNN`，
**不升版本、不建版本档案**（依据 `STATUS.md` §8.4 的项目特别约定——引擎以 submodule gitlink 被引用，
为文档错别字升版本会迫使所有宿主项目更新 gitlink，代价与收益不成比例）。
